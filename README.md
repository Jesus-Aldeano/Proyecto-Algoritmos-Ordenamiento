# Proyecto-Algoritmos-Ordenamiento

Nombre: Jesus Aldeano 

Proyecto académico desarrollado en Python para la gestión de un catálogo de productos, implementación y comparación de algoritmos de ordenamiento (Merge Sort, Quick Sort y Heap Sort), búsqueda binaria y búsqueda lineal. Incluye generación de datos, pruebas automatizadas, análisis de rendimiento, gráficos e informe técnico.
